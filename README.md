# صانع المقاطع القرآنية (Android)

تطبيق أندرويد يغلّف صانع المقاطع القرآنية (`app/src/main/assets/www/`) داخل WebView.
الواجهة كلها ملفات ويب ثابتة بدون خطوة بناء، والتطبيق نفسه بيضيف:

- حفظ الفيديو مباشرة في مجلد **Download/Inaba** (عبر MediaStore، بدون صلاحيات تخزين).
- إبقاء الشاشة مفتوحة أثناء التسجيل.
- منتقي الملفات الأصلي لأندرويد للصور والفيديو والصوت.
- أيقونة وتصميم داكن بنفس ألوان الموقع.

## المتطلبات

- Android Studio Ladybug أو أحدث، أو JDK 17 وGradle 8.10.2.
- أندرويد 10 (API 29) وما فوق.

## تشغيل المشروع

### من Android Studio

1. افتح مجلد المشروع من `File > Open`.
2. اضغط Sync. إذا طلب تحديث Gradle أو تثبيت SDK، وافق.
3. شغّل التطبيق على جهاز أو محاكي، أو اختر `Build > Build APK(s)`.

### من سطر الأوامر

```bash
gradle wrapper --gradle-version 8.10.2   # مرة واحدة، لإنشاء gradlew
./gradlew :app:assembleDebug
```

الـ APK بيطلع في `app/build/outputs/apk/debug/`.

### من GitHub Actions

كل push على `main` (أو تشغيل يدوي من تبويب Actions) بيبني نسخة debug تلقائياً.
حمّل الـ APK من قسم **Artifacts** في صفحة التشغيل: `inaba-quran-clips-debug`.

### تشغيل الواجهة في المتصفح

```bash
cd app/src/main/assets/www
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080/index.html`.

## الاختبارات

```bash
node --test tests/*.test.js   # البحث في القرآن، المكتبة، التخزين المحلي للتفضيلات
```

ملاحظة: على Node 22 لازم تكتب `tests/*.test.js` وما يكفي `tests/`.

اختبار `tests/library.test.js` يتحقق أيضاً من أن `backgrounds/manifest.json` المرفوع صالح. أي عنصر ناقص في المانيفست يفشل الاختبار.

اختبارات المتصفح (Playwright) ما هي في المستودع. تستخدم خدمات وهمية وبيانات تجريبية، ولا تعتمد على نص قرآني مكتوب يدوياً.

## هيكل الواجهة

```
app/src/main/assets/www/
  index.html          # الهيكل والتنسيق: ثماني صفحات (انظر "الصفحات")
  backgrounds/
    manifest.json     # مكتبة الخلفيات: مصدر الحقيقة (حالياً فارغة)
    LICENSES.md       # شروط الترخيص لكل ملف يُضاف للمكتبة
  js/
    arabic.js         # تطبيع النص العربي وبحث بالكلمات الجزئية مع تحمّل خطأ إملائي بسيط
    db.js             # IndexedDB: المسودات (حد 30) والكاش وخط المستخدم، ورسائل خطأ مفهومة
    services.js       # كل الاتصال بالإنترنت: alquran.cloud وMP3Quran، مع إعادة المحاولة والكاش الاختياري للصوت
    renderer.js       # محرك الرسم الوحيد: المعاينة والتصدير يستخدمانه، فالمعاينة تطابق الفيديو
    library.js        # التحقق من المانيفست (ترخيص ومصدر ومؤلف لكل عنصر)
    store.js          # التفضيلات والمفضلة وآخر المستخدم وسجل النشاط (localStorage)
    app.js            # الواجهة والحالة والتصدير والصفحات
```

## الصفحات

| الصفحة | ماذا تفعل |
|---|---|
| الرئيسية | أزرار سريعة، آخر ثلاث مسودات، آخر النشاط. أول صفحة تفتح |
| إنشاء مقطع | المحرر: ثلاث خطوات (الآيات والتلاوة، التصميم، المعاينة والتصدير)، وزر "مشروع جديد" |
| مشاريعي | المسودات: حفظ، فتح، إعادة تسمية، نسخ، حذف |
| مكتبة الخلفيات | بحث وفلاتر (فئة، نوع، مفضلة)، اختيار عشوائي، معاينة، ترخيص ومصدر ومؤلف معروض |
| القرّاء | قائمة القرّاء من MP3Quran، بحث، مفضلة، واستخدام القارئ في المحرر |
| المفضلة | الخلفيات والقرّاء المفضلون |
| الإعدادات | المظهر، الافتراضات للمشاريع الجديدة، الكاش، النسخ الاحتياطي، سجل النشاط |
| عن التطبيق | مصادر البيانات، وما هو متوفر وما هو غير متوفر |

## مصادر البيانات

| البيانات | المصدر | ملاحظة |
|---|---|---|
| نص القرآن (عثماني) | `api.alquran.cloud/v1/quran/quran-uthmani` | يُحفظ في IndexedDB بعد أول تحميل |
| التفسير الميسر | `api.alquran.cloud/v1/surah/{n}/ar.muyassar` | |
| الترجمات | `en.sahih` (Saheeh International) وغيرها | ترجمة معاني وليست نص القرآن |
| القرّاء والتوقيت والصوت | `mp3quran.net/api/v3` | التوقيت يُطبَّق بالملّي ثانية أو الثانية حسب مدة الملف |

**تحقق قبل النشر:**

- معرّفات الإصدارات (`ar.muyassar`، `fr.hamidullah`، `tr.diyanet`، `ur.jalandhry`، `id.indonesian`) ونقاط نهاية MP3Quran لم تُتحقق من الاتصال الحي. تأكد منها من قائمة `/v1/edition` قبل الاعتماد عليها.
- ترخيص كل ترجمة ومادة صوتية وبصرية قبل النشر التجاري.

## ما هو موجود

- بحث في القرآن بدون تشكيل، بالكلمات الجزئية، ومع تحمّل خطأ إملائي بسيط.
- اختيار السورة والنطاق، إضافة آية سابقة أو تالية، حذف آخر آية، كامل السورة. حدود: 286 آية و05:00.
- توقيت من MP3Quran، أو توقيت يدوي بالاستماع. لا توجد أوقات تقديرية تُعرض كأنها موثّقة.
- إزاحة المزامنة من −2000 إلى +2000 ms، مع معاينة مباشرة.
- معاينة بالتشغيل والإيقاف والبداية والتقديم والترجيع والصوت.
- **خلفيات:** صور وفيديوهات من الجهاز، ولون ثابت، وتكبير أو تصغير أو حركة جانبية، وتعديل السطوع والتباين والتشبّع والتمويه والتعتيم. ومكتبة خلفيات بتصنيفات، تُقرأ من `backgrounds/manifest.json`.
- **مكتبة الخلفيات:** كل عنصر يلزمه ترخيص ومصدر ومؤلف، وإلا يُستبعد ويظهر عدد المستبعد. خلفيات المكتبة تُستعاد تلقائياً بعد إعادة تحميل الصفحة أو فتح مسودة.
- نص: مواضع (أعلى، وسط، أسفل، مخصص)، خطوط، حجم، ارتفاع سطر، تباعد حروف، محاذاة، ظل، خلفية، إطار، شكل رقم الآية، مدة الظهور.
- **خطوط:** Amiri Quran، Amiri، Scheherazade New، Noto Naskh Arabic، وخط ترفعه من جهازك (TTF أو OTF أو WOFF، حتى 8 ميغابايت). الخط المرفوع يُحفظ على الجهاز فقط.
- قوالب جاهزة للتصميم.
- ترجمة وتفسير قابلان للإظهار والتعديل، مع موضع وخط ولون ومحاذاة.
- مقاسات 9:16 و16:9 و1:1 و4:5 ومخصص، ودقة 720p و1080p و1440p و**2160p (4K)**، ووضع خفيف للأجهزة الضعيفة.
- تصدير بالوقت الحقيقي مع شريط التقدم والمتبقي والإلغاء وإعادة المحاولة. المشاركة متاحة إذا دعمها الجهاز.
- **مشروع جديد:** يفرغ المحرر ويطبّق الإعدادات الافتراضية (المقاس والدقة والوضع الخفيف). يحتاج ضغطتين للتأكيد.
- مسودات محفوظة على الجهاز (حد 30): حفظ، فتح، إعادة تسمية، نسخ، حذف.
- **نسخ احتياطي:** تصدير كل المسودات والملفات المرفوعة والمفضلة في ملف JSON واحد، واستيراده على جهاز آخر. الاستيراد يضيف ولا يستبدل، ويحترم حد 30 مسودة.
- **كاش الصوت (اختياري):** من الإعدادات، يُحفظ الصوت المجلوب من MP3Quran لإعادة استخدامه دون شبكة. مسح الكاش لا يمسح المسودات ولا الخط المرفوع.
- **مفضلة:** خلفيات من المكتبة وقرّاء.
- **سجل النشاط:** تصدير الفيديو، حفظ المسودات وفتحها وحذفها، إضافة الخلفيات، جلب الصوت، النسخ الاحتياطي. محفوظ على الجهاز فقط.
- إعدادات المحرر تبقى بعد إعادة تحميل الصفحة. الملفات المرفوعة لا تبقى إلا في المسودات.
- وضع فاتح وداكن.

## ما هو غير موجود بعد

- **محتوى مكتبة الخلفيات:** البنية جاهزة، لكن المكتبة فارغة عن قصد. لا نضيف صوراً أو فيديوهات بدون ترخيص مؤكد. الشروط والخطوات في `backgrounds/LICENSES.md`.
- **خط KFGQPC:** غير مرفق لأن ترخيصه لا يسمح بإعادة التوزيع. يمكن رفع نسختك الخاصة من الإعدادات إذا كان ترخيصك يسمح بذلك.
- **حسابات المستخدمين والمزامنة السحابية:** تحتاج خادماً ومزوّد تسجيل دخول وكلفة تشغيل، ولم تُضَف. البديل الحالي: النسخ الاحتياطي اليدوي.
- **روابط مشاركة عامة:** تحتاج رفع الفيديو لخادم. المتوفر: المشاركة عبر نافذة الجهاز.
- **إعادة ترتيب الآيات:** غير مطبّقة، لأن الترتيب يتبع المصحف.
- **تقسيم المقطع بين سورتين:** النطاق داخل سورة واحدة.
- **تنزيل قابل للاستئناف:** عند انقطاع الشبكة يعيد التطبيق المحاولة (3 مرات)، ولا يكمل من حيث توقف.
- **صيغة MP4 مضمونة:** التصدير يستخدم MP4 إذا دعمه المتصفح، وإلا WebM. بعض المتصفحات (مثل Chromium في بيئة الاختبار) تسجّل WebM فقط.
- **4K على الأجهزة الفعلية:** الخيار موجود، لكن لم يُختبر على جهاز أندرويد حقيقي. التسجيل أبطأ بكثير، وقد يفشل على الأجهزة الضعيفة.
- **بنية Next.js:** المشروع ملفات ويب ثابتة لأن غلاف أندرويد يحمّلها مباشرة. الانتقال لـ Next.js يحتاج تصديراً ثابتاً وتعديل الغلاف.

## كيف يعمل التصدير

1. الصفحة تُحمَّل من `https://appassets.androidplatform.net/assets/www/index.html` عبر `WebViewAssetLoader`، فتشتغل بأصل حقيقي وتقدر تستخدم `fetch` وMediaRecorder بشكل طبيعي.
2. يُحمَّل الصوت كاملاً في الذاكرة (حتى يدخل التسجيل)، ثم يُرسم كل إطار بنفس دالة المعاينة، ويُسجَّل الكانفس مع الصوت.
3. عند انتهاء التسجيل، الصفحة ترسل الفيديو للتطبيق على شكل أجزاء base64 عبر الجسر `InabaBridge`.
4. التطبيق يكتب الأجزاء بملف مؤقت ثم ينقله إلى `Download/Inaba/` ويعرض مكانه في الصفحة.

## ملاحظات مهمة

- **التسجيل يتوقف إذا خرج التطبيق للخلفية.** WebView بيوقف الرسم والمؤقتات لما التطبيق يروح للخلفية، فلا تقفل الشاشة ولا تطلع من التطبيق أثناء التسجيل.
- **الصيغة:** إذا الجهاز يدعم MP4 (H.264) بيسجّل MP4، وإلا WebM. ملفات WebM الناتجة من المتصفح ما تحمل مدة في الترويسة، فبعض المشغّلات تعرض المدة بشكل غير دقيق، لكنها تُشغَّل بشكل عادي.
- **الصوت من موقع خارجي:** إذا منع الموقع الوصول عبر CORS، المعاينة تعمل، لكن التصدير يُمنع ويطلب رفع الملف يدوياً.
- **الاتصال بالإنترنت مطلوب** لجلب نص السورة والتفسير والصوت. بعد أول تحميل، نص القرآن يبقى محفوظاً على الجهاز.
- **البسملة:** تُحذف من أول آية للعرض فقط (ما عدا الفاتحة والتوبة). النص المحفوظ في الكاش كما جاء من alquran.cloud.
- **التخزين الممتلئ:** إذا امتلأت مساحة الجهاز، تظهر رسالة عربية تقترح حذف مسودات أو مسح الكاش.

## الحالة الحالية

- المشروع مكتوب بدون بناء محلي (ما في Android SDK في بيئة التطوير). أول بناء فعلي بيصير على GitHub Actions.
- إذا فشل البناء، ارفع سجل الخطأ وبصلحه.
- ملف `gradlew` غير موجود بعد. أنشئه بالأمر أعلاه إذا بدك تبني من سطر الأوامر.
- الكود الأندرويدي (`MainActivity.kt`، `ClipBridge.kt`) ما تغيّر في هذه الدفعة.
- الاختبارات الوحدية (`node --test tests/*.test.js`) تمر. اختبارات المتصفح تغطي المكتبة والمفضلة والقرّاء والإعدادات والمشروع الجديد والنسخ الاحتياطي والخط المرفوع وكاش الصوت، وتمر أيضاً. كلها تستخدم خدمات وهمية، فالاتصال الحي بـ alquran.cloud وMP3Quran لم يُتحقق منه بعد.
