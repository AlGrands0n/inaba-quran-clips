# صانع المقاطع القرآنية (Android)

تطبيق أندرويد يغلّف صانع المقاطع القرآنية (`app/src/main/assets/www/index.html`) داخل WebView.
الواجهة والمنطق كلهم في صفحة واحدة، والتطبيق نفسه بيضيف:

- حفظ الفيديو مباشرة في مجلد **Download/Inaba** (عبر MediaStore، بدون صلاحيات تخزين).
- إبقاء الشاشة مفتوحة أثناء التسجيل.
- منتقي الملفات الأصلي لأندرويد للصور والفيديو والصوت.
- أيقونة وتصميم داكن بنفس ألوان الموقع.

## المتطلبات

- Android Studio Ladybug أو أحدث، أو JDK 17 وGradle 8.10.2.
- أندرويد 10 (API 29) وما فوق.

## تشغيل المشروع

### من Android Studio

1. افتح مجلد المشروع من `File > Open`.
2. اضغط Sync. إذا طلب تحديث Gradle أو تثبيت SDK، وافق.
3. شغّل التطبيق على جهاز أو محاكي، أو اختر `Build > Build APK(s)`.

### من سطر الأوامر

```bash
gradle wrapper --gradle-version 8.10.2   # مرة واحدة، لإنشاء gradlew
./gradlew :app:assembleDebug
```

الـ APK بيطلع في `app/build/outputs/apk/debug/`.

### من GitHub Actions

كل push على `main` (أو تشغيل يدوي من تبويب Actions) بيبني نسخة debug تلقائياً.
حمّل الـ APK من قسم **Artifacts** في صفحة التشغيل: `inaba-quran-clips-debug`.

## كيف يعمل التصدير

1. الصفحة تُحمَّل من `https://appassets.androidplatform.net/assets/www/index.html` عبر `WebViewAssetLoader`،
   فتشتغل بأصل حقيقي وتقدر تستخدم `fetch` وMediaRecorder بشكل طبيعي.
2. عند انتهاء التسجيل، الصفحة ترسل الفيديو للتطبيق على شكل أجزاء base64 عبر الجسر `InabaBridge`.
3. التطبيق يكتب الأجزاء بملف مؤقت ثم ينقله إلى `Download/Inaba/` ويعرض مكانه في الصفحة.

## ملاحظات مهمة

- **التسجيل يتوقف إذا خرج التطبيق للخلفية.** WebView بيوقف الرسم والمؤقتات لما التطبيق يروح للخلفية،
  فلا تقفل الشاشة ولا تطلع من التطبيق أثناء التسجيل.
- **الصيغة:** إذا الجهاز يدعم MP4 (H.264) بيسجّل MP4، وإلا WebM. أغلب الأجهزة الحديثة تدعم WebM على الأقل.
- **الصوت من موقع خارجي:** إذا ما سمح الموقع المصدر بالوصول عبر CORS، الصوت بيشتغل بس التصدير ممكن يطلع بدون صوت.
  الصفحة بتعرض تحذيراً في هذه الحالة.
- **الاتصال بالإنترنت مطلوب** لجلب نص السورة والصوت من alquran.cloud وMP3Quran.

## الحالة الحالية

- المشروع مكتوب بدون بناء محلي (ما في Android SDK في بيئة التطوير). أول بناء فعلي بيصير على GitHub Actions.
- إذا فشل البناء، ارفع سجل الخطأ وبصلحه.
- ملف `gradlew` غير موجود بعد. أنشئه بالأمر أعلاه إذا بدك تبني من سطر الأوامر.

## هيكل المشروع

```
app/src/main/
  AndroidManifest.xml
  java/com/inaba/clips/
    MainActivity.kt   # الشاشة: WebView + منتقي الملفات + زر الرجوع
    ClipBridge.kt     # الجسر: حفظ الفيديو في التنزيلات وإبقاء الشاشة مفتوحة
  assets/www/
    index.html        # صانع المقاطع (نسخة من الموقع + حفظ أصلي)
  res/                # الأيقونة، الألوان، الثيم، النصوص
```
